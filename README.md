# hibi works. Portfolio

## ファイル構成
- index.html：ページ本体
- style.css：デザイン・レスポンシブ
- script.js：スマホメニュー・実績フィルター
- assets/hero.svg：仮のヒーロー画像
- assets/cta.svg：仮のCTA背景

## 使い方
index.html をブラウザで開けば確認できます。

## 実案件用に変更する場所
1. assets/ の仮画像を実際の画像に差し替える
2. 各 Works の href を実績詳細ページへ変更
3. お問い合わせフォームを Contact Form 7 等に置き換える
4. About のプロフィール情報を実際の内容へ変更
5. 必要に応じて colors / font / spacing を style.css の :root から調整
